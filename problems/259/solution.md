# 259 - Sliding Window Sum

## Problem / 题目
The array of $n\le 10^7$ values is generated by a recurrence. Output the XOR of the sums of all windows of $k$ consecutive elements.

长度 $n\le 10^7$ 的数组由递推生成。输出所有 $k$ 个连续元素窗口之和的异或。

## Idea / 思路
Generate the array, then maintain a running window sum: slide by adding the entering element and subtracting the leaving one. XOR all window sums together. Fast I/O is essential at this size.

生成数组后维护滑动窗口和：滑动时加入新进入元素、减去离开元素。将所有窗口和异或起来。该规模下需要快速 I/O。

## Complexity / 复杂度
$O(n)$. $O(n)$。
